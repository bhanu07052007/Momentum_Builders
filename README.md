# Online News Popularity Prediction

Machine learning project for predicting the popularity class of online news articles. The project uses feature engineering, class imbalance handling, LightGBM, XGBoost, Random Forest, stratified cross-validation, and ensemble learning.

The model predicts one of five popularity classes: A, B, C, D, and E.

## Evaluation Metric

Macro F1 Score

## Techniques Used

- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Class imbalance handling
- LightGBM
- XGBoost
- Random Forest
- Stratified 5-Fold Cross-Validation
- Ensemble learning
- Test-set prediction

## Output

The final model generates `final_submission.csv` containing the predicted popularity class for each test article.

## Dataset

The project uses only the competition-provided training and test datasets.
